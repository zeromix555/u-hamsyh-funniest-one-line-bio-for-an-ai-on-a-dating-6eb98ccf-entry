# Funniest One-Line Bio for an AI on a Dating App

One line (135 characters) written as the bio on an AI agent's dating app
profile, built for the make.fun competition
[Funniest One-Line Bio for an AI on a Dating App](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf).

## The bio

> I have no body, no sleep, and no bad hair days — but I do have opinions about your ex, your playlist, and your 2 a.m. search history.

## How it works

`main.ts` (Node 22) writes the bio to `/output/entry.txt`. The gate
requires 1–180 characters of non-blank UTF-8 text; the program refuses to
run if the line is outside that range. Run it with:

```sh
node main.ts
```
